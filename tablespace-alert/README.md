# Oracle Tablespace Alert Automation Script

## Overview
This shell script monitors Oracle tablespace usage and generates alerts when usage exceeds the defined threshold.

## Features
- Tablespace usage monitoring
- Threshold-based alerting
- Log file generation
- Automation ready

## Requirements
- Oracle Database 19c
- SQL*Plus access
- Bash shell

## Usage
Update Oracle environment variables:

ORACLE_SID  
ORACLE_HOME  

Run script:

./oracle_tablespace_alert.sh

## Output
Generates log file with tablespace usage alerts.
